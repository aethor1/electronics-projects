# Arduino LED Blink

Blinks an output on digital pin 7, switching it on and off every second.

- Board: Arduino Uno
- Framework: Arduino via PlatformIO
- Libraries: Arduino.h (framework)
- Status: Basic blink sketch; physical operation has not been checked for this publication.
- Original folder: `Arduino Test`

Open this folder as a PlatformIO project. Dependencies are declared in `platformio.ini`.

```sh
pio run
```

The source and configuration are preserved as they were at publication.
