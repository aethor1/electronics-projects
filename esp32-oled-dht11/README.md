# ESP32 Temperature and Humidity Display

Displays DHT11 temperature in Celsius/Fahrenheit and humidity on a 128x64 SSD1306 OLED.

- Board: ESP32 DOIT DevKit V1
- Framework: Arduino via PlatformIO
- Libraries: Adafruit SSD1306, Adafruit GFX, DHT sensor library, Adafruit Unified Sensor
- Status: Display/sensor prototype; physical operation has not been checked for this publication.
- Original folder: `ESP display test`

Open this folder as a PlatformIO project. Dependencies are declared in `platformio.ini`.

```sh
pio run
```

The source and configuration are preserved as they were at publication.
